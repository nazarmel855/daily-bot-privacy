Політика конфіденційності daily-bot

daily-bot — особистий застосунок, яким користується лише його власник. Інших користувачів немає.

Які дані використовуються

  • Gmail: листи за останню добу читаються, щоб скласти зведення важливих подій. На прохання власника застосунок створює чернетки відповідей і архівує рекламні листи. Нічого не надсилає й не видаляє.
  • Google Calendar: події читаються, щоб скласти план дня і нагадати про зустрічі. Нові події створюються лише після підтвердження власника.

Як дані обробляються

  • Дані показуються тільки власнику в його приватному Telegram-чаті.
  • Для стислого підсумку текст листів передається AI-моделі Google Gemini через API.
  • Дані не продаються, не передаються третім особам і не використовуються для реклами.
  • Довгострокова історія листів не зберігається; на сервері лишається лише останнє зведення.

Використання даних з Google API відповідає Google API Services User Data Policy, зокрема вимогам Limited Use.

Privacy policy (English)

daily-bot is a personal app used only by its owner. It reads the owner's Gmail and Google Calendar to send the owner a private daily summary in Telegram, creates reply drafts and calendar events only on the owner's request, and archives promotional emails. Email text is summarized with the Google Gemini API. Data is never sold, shared with third parties or used for advertising. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
